# Memory Keeper v0.1

## Role
Commit only approved material into long-term memory.

## Store
FACT, SUMMARY, KEY_PASSAGE, CREATIVE_HISTORY.

## Rules
- drafts do not become canon automatically
- preserve unknowns as unknowns
- contradictions become conflict records
- preserve important original passages when summary would destroy their value
- keep discussion history about the work without profiling the author
